# Security Policy

CoreX Signal AI welcomes responsible reports that help protect the public product experience and supporting services.

## Reporting a security issue

Please report suspected security vulnerabilities privately to:

**info@corexsignalai.com**

Include enough detail for the team to understand and reproduce the issue safely:

- affected URL or product area;
- clear description of the issue;
- minimal reproduction steps;
- potential impact;
- screenshots or logs with secrets and personal data removed.

Do **not** publish a vulnerability publicly before the team has had a reasonable opportunity to investigate.

## Responsible testing boundaries

Security research must remain non-destructive. Do not:

- access, modify, copy or delete data that is not yours;
- attempt credential theft or social engineering;
- perform denial-of-service, traffic flooding or resource exhaustion;
- exploit a vulnerability beyond the minimum necessary to demonstrate it;
- test payment, account or user systems with unauthorized data;
- exfiltrate secrets, tokens, personal information or private model / infrastructure data;
- disrupt live users or service availability.

If testing could affect real users or production availability, stop and contact us first.

## Scope of this repository

This public `.github` repository contains brand, documentation and community files. Proprietary model code, production infrastructure, credentials and internal security configuration are not published here.

Thank you for helping keep CoreX Signal AI safer.
