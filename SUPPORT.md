# CoreX Signal AI Support

For product and account assistance, use the official CoreX Signal AI support channels rather than GitHub Issues.

## Product & account support

**Email:** [info@corexsignalai.com](mailto:info@corexsignalai.com)  
**Website:** https://corexsignalai.com/  
**Live Dashboard:** https://api.corexsignalai.com/

Use official support for:

- account access;
- subscription / plan questions;
- dashboard access;
- symbol or market availability;
- language settings;
- notifications;
- signal / dashboard behavior;
- billing or payment questions;
- live-service incidents;
- business enquiries.

## GitHub Issues

GitHub Issues in this repository are intended only for:

- public documentation corrections;
- broken public links;
- accessibility problems in GitHub documentation;
- factual corrections to the public organization profile.

Do not post account details, payment information, credentials, private logs, API keys, personal information or vulnerability details in a public issue.

For security reports, see [SECURITY.md](SECURITY.md).
