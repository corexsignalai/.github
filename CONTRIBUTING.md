# Contributing

Thank you for helping improve the public CoreX Signal AI GitHub presence.

This repository is focused on **organization-profile content, public product documentation and community metadata**. It is not the public source-code repository for the CoreX Signal AI engine.

## Useful contributions

Good contributions include:

- fixing broken links;
- correcting typos or factual errors;
- improving accessibility and alt text;
- improving public documentation clarity;
- reporting outdated product descriptions;
- suggesting clearer navigation between official resources.

## Please do not submit

- proprietary model code;
- production configuration;
- credentials, tokens or secrets;
- user data;
- copied third-party material without permission;
- unverified performance claims;
- guaranteed-return language;
- confidential business or infrastructure information.

## Product support and security

For account or product support, see [SUPPORT.md](SUPPORT.md).

For vulnerabilities, do not open a public issue. Follow [SECURITY.md](SECURITY.md).
